Points 50 + 50 with video Build on ai.pharos.xyz What you'll build A small agent or script that reads live state from a deployed Pharos contract through Chain MCP and presents it in plain language. Pick any public contract (a token, vault, or registry) and turn its raw storage and view calls into something a non-developer can read. Requirements 01 Reads at least 3 different values from one contract via Chain MCP (e.g. name, totalSupply, owner, a balance). 02 Shows the contract address and the block number the data was read at. 03 Formats raw values for humans: token decimals applied, addresses labelled. 04 Includes a short README: which contract you chose, how to run it, sample output. Reviewers score against this list. Missing items can mean partial points. What to submit A proof link reviewers can open — a share link from ai.pharos.xyz, a tx hash on the explorer, or a deployed demo. A repo link if you wrote code.
